# Шаурма-Радар — Android APK

Проект упаковывает HTML-версию в Android-приложение через WebView. В APK включён сам HTML, поэтому стартовый экран не требует хостинга. Карта и внешние сервисы (Leaflet/OpenStreetMap/Nominatim) требуют интернет.

## Как получить APK без компьютера

1. Создайте новый **публичный** репозиторий на GitHub (например, `Shaurma-Radar-Android`).
2. Загрузите содержимое этой папки в корень репозитория. Важно: загрузить папки `app`, `.github` и файлы Gradle, а не только ZIP как один файл.
3. Откройте вкладку **Actions** и выберите **Build Android APK**. Если появится кнопка **I understand my workflows, go ahead and enable them**, нажмите её.
4. Нажмите **Run workflow** и подтвердите запуск.
5. Когда запуск станет зелёным, откройте его и внизу страницы **Artifacts** скачайте `Shaurma-Radar-APK`.
6. Распакуйте скачанный ZIP и установите `app-debug.apk` на Pixel 7. Android может попросить разрешить установку приложений из браузера/файлового менеджера.

APK подписывается стандартным debug-ключом сборочной среды, подходит для личной установки. Для публикации в Google Play понадобится отдельная release-подпись.
